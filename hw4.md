## Подготовка базы данных

В задачах используется следующая схема (**PostgreSQL**):

```sql
CREATE TABLE users (
    id   BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    age  INT NOT NULL,
    city TEXT NOT NULL
);

CREATE TABLE orders (
    id      BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users (id),
    item    TEXT NOT NULL,
    price   INT NOT NULL
);
```

## 📋 Задачи и решения

### Задача 1: Долгожитель

Найдите **самого старого пользователя из Москвы**. Выведите его имя и возраст.

#### Решение
```sql
SELECT name, age 
FROM users
WHERE city = 'Москва'
ORDER BY age DESC
LIMIT 1;
```

---

### Задача 2: Перепись населения

Посчитайте **количество пользователей по городам**. Выведите только те города, где больше одного пользователя, и отсортируйте результат по количеству по убыванию (при равенстве — по названию города по алфавиту).

*Ожидаемый результат:* Москва — 3, Казань — 2.

#### Решение

```sql
SELECT city, COUNT(id) AS people 
FROM users
GROUP BY city
HAVING COUNT(id) > 1
ORDER BY people DESC, city ASC;
```

### Задача 3: Учёт трат

Для **каждого пользователя** посчитайте суммарную стоимость его заказов. Выведите имя и сумму, отсортируйте по сумме по убыванию.

*Важно:* пользователи без заказов не должны потеряться — у них в колонке суммы должен быть `0`, а не пустая строка и не пропущенная строка.

*Ожидаемый результат:* Борис — 120000, Глеб — 57000, Анна — 51500, Егор — 38000, Вера — 0, Дина — 0.

#### Решение

```sql
SELECT 
    u.name, 
    COALESCE(SUM(o.price), 0) AS total_spent
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
GROUP BY u.id, u.name
ORDER BY total_spent DESC;
```

### Задача 4: Любители музыки

Выведите **имена пользователей, которые покупали наушники**, без повторов, отсортировав по имени. Важное условие: у пользователя может быть несколько заказов с наушниками, но в результате его имя должно встретиться один раз.

*Ожидаемый результат:* Глеб, Егор.

#### Решение

```sql
SELECT DISTINCT u.name
FROM users u
JOIN orders o ON u.id = o.user_id
WHERE o.item = 'наушники'
ORDER BY u.name ASC;
```

### Задача 5: Бюджетный выбор

Выведите **название товара и цену самого дешёвого заказа** среди всех заказов дороже 10000 рублей. Если таких заказов (с минимальной ценой) несколько — выведите все.

*Ожидаемый результат:* наушники — 12000.

#### Решение

```sql
SELECT item, price
FROM orders
WHERE price > 10000
  AND price = (
      SELECT MIN(price) 
      FROM orders 
      WHERE price > 10000
  );
```
